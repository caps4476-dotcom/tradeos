⚠ FIREBASE EINRICHTEN

Damit deine Daten online gespeichert werden, musst du einmalig Firebase einrichten und den Code unten in diese Datei einfügen.

1
Gehe zu console.firebase.google.com und erstelle ein neues Projekt (z.B. „tradeos")
2
Klick auf das Web-Symbol </> → App registrieren → du bekommst einen Konfigurations-Block
3
Gehe in der linken Menüleiste zu Build → Firestore Database → Datenbank erstellen → im Testmodus starten
4
Gehe zu Authentication → Sign-in method → aktiviere E-Mail/Passwort
5
Ersetze den Platzhalter unten in der Datei index.html mit deiner echten Firebase-Konfiguration:
